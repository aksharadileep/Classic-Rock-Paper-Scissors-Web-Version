# 🎮 Stone Paper Scissors Pro

An animated and modern Rock Paper Scissors web game built using:

- HTML5
- CSS3 (Glassmorphism + Animations)
- JavaScript (Game Logic)
- Animate.css

## ✨ Features

- Splash screen with mode selection
- Play vs Computer
- Local 2 Player Mode
- Sound effects using Web Audio API
- Score tracking (Best of 5)
- Modern UI with animations
- Fully responsive design
