# 🎮 Classic Rock Paper Scissors - Web Version

A modern and interactive browser-based implementation of the classic Rock Paper Scissors game, designed with engaging animations, responsive layouts, and smooth gameplay mechanics. The project demonstrates core frontend development concepts including DOM manipulation, event handling, game logic implementation, and responsive web design.

---

# 📌 Overview

This project recreates the timeless Rock Paper Scissors game with a modern user interface and enhanced gameplay experience.

Players can compete against the computer or challenge a friend using local multiplayer mode while enjoying smooth animations, sound effects, and real-time score tracking.

---

# ✨ Features

### 🎯 Game Modes

* Single Player (Player vs Computer)
* Local Multiplayer (Player vs Player)

### 🎮 Gameplay Features

* Real-time score tracking
* Best-of-5 game system
* Instant winner detection
* Interactive game controls
* Dynamic result display

### 🎨 User Interface

* Modern Glassmorphism Design
* Animated Splash Screen
* Smooth CSS Animations
* Responsive Layout
* Mobile-Friendly Experience

### 🔊 Audio & Effects

* Sound effects using Web Audio API
* Interactive feedback animations
* Enhanced user engagement

# 🛠️ Tech Stack

| Technology       | Purpose                                |

| CSS3             | Styling, Animations & Glassmorphism UI |
| JavaScript (ES6) | Game Logic & Interactivity             |
